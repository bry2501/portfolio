# Portfolio site — notes for Claude

- Static site, no build step. It is a SINGLE PAGE organized **by client**: all content is in `index.html`. Header nav = `#clients` (the Overview) and `#contact`. Page order: hero → quote band → Overview → client sections → word cloud → Contact. Each client is `<section class="work client" id="<client-slug>">` containing `.channel` blocks (`<h3 class="ch-title">Landing Pages / Social Media / Facebook Ads / Email / Website / outlet name</h3>`) that hold the project components, and ends with an `↑ All clients` link. To add a client: add the section, then an `<li><a class="pill" href="#slug"><b>Name</b><span>Channels</span></a></li>` under the right sector column in `.sectors` (navy pills, no icons). EVERY pill jumps in-page; organizations without work samples go in the non-clickable `.also` row, never as links. Alternate `alt` on sections for background rhythm. Order (Overview columns AND client sections): Healthcare → Business & Media → Education → Ministry & Nonprofit, because Bryan mainly applies to healthcare and business orgs. Exception: the Publications SECTION sits after A Better Florida, right before the ministry clients (its pill stays in the Business & Media column).
- Home/section styles live in `assets/css/home.css`; `assets/css/style.css` holds base styles and the header.
- Prefer the existing section classes in `home.css` (`.work`, `.work-head`, `.social-row`, `.lp`, `.email-grid`, `.svc`, `.h-band`) over inline styles. Beware: `style.css` still has generic classes like `.client`, `section` and `.quote`; use distinct names to avoid collisions.
- Images go in `assets/img/` as optimized `.webp` (≤1400px wide). Give every image real `alt` text. Add `class="zoom"` to make an image open full-size on click.
- Résumé file: `assets/docs/bryan-rivera-resume.docx` (linked from the Resume button in the hero).
